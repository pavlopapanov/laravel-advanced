# Order Invoices

- Додати бібліотеку https://github.com/LaravelDaily/laravel-invoices
- Створити сервіс по генерації інвойсів
- Створити сповіщення на email для клієнтів (по email з замовлення) та додати туди файл інвойсу
- Додати перегляд інвойсів на сторінці"Thank you" для авторизованих користувачів (додати полісі для перевірки що користувач є власником замовлення)
