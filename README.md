# Laravel API

- Створити авторизацію через АРІ
- Створити версіонність для роутів v1, v2
- Створити по продукт контролеру на кожну версію і зробити до них різни ресурси на відповідь
- Створити ресурс категорій і додати категорії у відповідь до ресурсу продукту (ім'я категорії та її посилання)
- Кожна версія продукт контролера повинна віддавати різні данні
