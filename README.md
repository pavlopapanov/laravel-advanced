# Laravel - Admin Dashboard & Categories CRUD

Створюємо адмін дашборд:

- Admin/Dashboard контролер та роут до нього
- робимо лейаут для адмінки
- додаємо меню для навігації по адмінці

Створюємо CRUD контролер для категорій

- мають бути реалізовані всі екшени (index, create, store, edit, update, destroy)
- додати вʼюшки
- додати валідації форм (не забуваємо перевірити права доступу до екшна)
- додати нотифікації
